Deux types de problèmes

MAX — max f(x) = c₁x₁ + … + cₙxₙ avec des contraintes ≤ et x ≥ 0 : on applique le simplexe directement. Les variables d'écart xn+1…xn+m forment la base de départ.

MIN — min f(y) = c₁y₁ + … + cₙyₙ avec des contraintes ≥ et y ≥ 0 (le primal) : on écrit le dual, qui est un problème de MAX,

max f(x) = b₁x₁ + … + bₘxₘ   avec   Aᵀx ≤ c

On le résout avec le simplexe, puis on lit la solution du primal dans le dernier tableau : yⱼ = − (valeur de la ligne f sous la variable d'écart de la contrainte j du dual). Par dualité forte, f min = f max.

Règles du simplexe

  1. Variable entrante : la plus grande valeur de la ligne f, en ne regardant que les colonnes des variables du problème (pas celles des variables d'écart). En cas d'égalité, on prend la dernière.
  2. Variable sortante : le plus petit rapport b / coefficient, seulement pour les coefficients > 0. Si aucun coefficient n'est > 0, le problème est non borné.
  3. Pivot : on divise la ligne du pivot par le pivot, puis on fait apparaître des 0 dans la colonne : Lᵢ ← Lᵢ − (coef) × Lpivot. C'est la règle du rectangle du cours (case − coin₁ × coin₂ / pivot), appliquée à une ligne entière d'un coup.
  4. Arrêt quand toutes ces valeurs de la ligne f sont ≤ 0.
  5. Si une variable hors base a 0 dans la ligne f, il existe une autre solution optimale : on fait un pivot de plus.

Lecture du tableau

La colonne b est la première colonne du tableau, puis la colonne j contient la variable xⱼ. Dans le calcul, la case b de la ligne f contient −f ; on affiche son opposé pour lire directement la valeur de f. Une variable en base vaut la valeur de b sur sa ligne, une variable hors base vaut 0.

Tous les calculs sont faits en fractions exactes (20/3, 1/3…), jamais en nombres à virgule.

À propos de cette application

Le cœur du projet est mon programme Python simplex.py : l'algorithme du simplexe par la méthode des tableaux, les règles de choix des variables entrante et sortante, la détection des solutions multiples et la résolution des problèmes de min par le dual. Il est disponible dans l'onglet « Code ».

L'interface graphique a été mise en place avec l'aide d'une IA, afin de simplifier l'utilisation de l'application et la visualisation de l'algorithme du simplexe. Elle est basée sur mon code Python : le calcul en ligne est une traduction fidèle de simplex.py en JavaScript (mêmes fonctions, mêmes règles, calculs exacts en fractions), pour pouvoir tourner directement dans le navigateur.

Les résultats affichés sont les mêmes que ceux du programme Python lancé en console avec python3 simplex.py.

Note pour le professeur

Pour moi, l'essentiel de ce projet est de comprendre comment fonctionne l'algorithme du simplexe : construire le tableau, choisir les variables entrante et sortante, faire le pivot, reconnaître l'optimum, et savoir passer par le dual pour un problème de minimisation. C'est ce travail que j'ai fait moi-même dans le programme Python.

Je pense que l'utilisation de l'IA n'enlève rien à cette compréhension, à condition de s'en servir comme d'un outil et non comme d'une béquille. Ces technologies font désormais partie du métier : il faut savoir s'y adapter pour être plus efficace, sans en devenir dépendant.

Le plus important reste de maîtriser les méthodes et les algorithmes de base. L'implémentation, elle, relève des choix du développeur : langage, outils, interface. Ici, j'ai choisi de m'appuyer sur l'IA pour la partie interface, afin de rendre l'algorithme plus facile à utiliser et à visualiser.
